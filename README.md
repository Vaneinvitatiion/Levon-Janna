# Լևոն և Ժաննա — հարսանեկան հրավեր

Բացեք `index.html`-ը բրաուզերում կամ վերբեռնեք ամբողջ թղթապանակը ցանկացած հոստինգ։

## Թղթապանակի կառուցվածքը

```
index.html
style.css
script.js
music.mp3            <- երգը (Hayko, «Երանի սրտիս»)
images/
  hero.jpg           <- բացման էկրանի թափանցիկ ֆոնային նկար (նրանց լուսանկարը)
  story-1.jpg        <- «Սեր լիքը Սեր» (3 ուղղահայաց նկար, 4:5)
  story-2.jpg
  story-3.jpg
  couple.jpg         <- պատռված եզրերով մեծ նկար (4:5)
  church.jpg         <- եկեղեցու նկար
  restaurant.jpg     <- ռեստորանի նկար
```

Նկարները արդեն դրված են `images/` թղթապանակում։ CSS-ով դրանք ցուցադրվում են սև-սպիտակ (բացման էկրանը՝ մուգ)։ Գունավոր թողնելու համար `style.css`-ից հանեք `grayscale(1)`-ը։

## Ինչպես փոխել

- Ամսաթիվ, հետհաշվարկի ժամ, երաժշտություն, RSVP՝ `script.js`-ի սկզբի `CONFIG`
- Ժամանակացույց և տեքստեր՝ `index.html`
- «Քարտեզ» հղումներ՝ `index.html`, `class="map"` հղումների `href` (փոխարինեք Google Maps-ի ճշգրիտ հղումով)
- RSVP վերջնաժամկետ՝ `index.html`, `data-rsvp-deadline` տեքստը
- Գույներ, տառատեսակներ, չափեր՝ `style.css`-ի սկզբի `:root`
